# Wattpad

> Wattpad is a Toronto-based social storytelling platform where a global community of writers and readers share serialized original fiction. Acquired by Naver (WEBTOON) in 2021. Wattpad does not currently offer a public developer API — its former developer program (developer.wattpad.com) was discontinued around April 2018 and the API is now internal-only.

This profile is maintained by the API Evangelist network (api-evangelist/wattpad).

## API surface

- No public API: the former developer API (api.wattpad.com v2-v5) was closed to the public around April 2018; developer.wattpad.com redirects to the homepage and API keys were invalidated.
